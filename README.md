# ⚡ VoltAgent — بيئة بحثية للتحكم الذكي في شحن البطارية مع المولد

**الحالة الحالية: نموذج بحثي يعمل بالمحاكاة فقط. لا يتصل بمولد أو إنفرتر أو بطارية حقيقية.**

VoltAgent مشروع تجريبي لدراسة استخدام التعلم المعزز PPO في اقتراح تغييرات تدريجية على تيار شحن بطارية، مع مراقبة تردد مولد افتراضي وحالة حرارية مبسطة.

> **تنبيه هندسي:** قيم القدرة والجهد والتيار ومعاملات القصور واستجابة الحاكم والحرارة في البيئة الحالية افتراضات تعليمية قابلة للتغيير، وليست مواصفات معدات أو حدود حماية معتمدة. لا تستخدم النموذج للتحكم في معدات فعلية أو لاتخاذ قرارات سلامة كهربائية.

## ما الذي تم إصلاحه؟

- إعادة بناء بيئة المحاكاة لتكون أوضح، قابلة لإعادة الإنتاج، وتستخدم معادلات مبسطة لكنها أكثر اتساقًا من النسخة السابقة.
- جعل الملاحظات تشمل التردد ومعدل تغيره وتيار الشحن وحرارة البطارية والحمل وهدف تيار الشحن والقدرة الميكانيكية الافتراضية.
- فصل سجلات النسخة القديمة عن سجلات المحاكاة الجديدة.
- إزالة التحديث التلقائي للنموذج من ملف CSV. النسخة الحالية لا تدعي وجود مسار تعلم مستمر من بيانات ميدانية.
- إضافة بيانات وصفية للنموذج بعد التدريب، وفحص توافقها عند الاستدلال.
- إضافة اختبارات أساسية وتقرير مراجعة هندسية.
- تحويل `requirements.txt` إلى UTF-8 مع تحديد المتطلبات المباشرة بدل قائمة طويلة من التبعيات العابرة.

## الإعداد على Windows

استخدم Python 3.10 أو أحدث؛ يعتمد إعداد الحزم على Stable-Baselines3 2.9.x وGymnasium 1.3 أو أحدث ضمن السلاسل المحددة في `requirements.txt`.

افتح PowerShell داخل مجلد المشروع ونفّذ:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

إذا منع PowerShell تفعيل البيئة بسبب سياسة التنفيذ، افتح موجه الأوامر `cmd` واستخدم:

```bat
.venv\Scripts\activate.bat
```

## التدريب

```powershell
python train_agent.py
```

لتغيير عدد خطوات التدريب والبذرة العشوائية:

```powershell
python train_agent.py --timesteps 50000 --seed 42 --eval-episodes 8
```

يحفظ التدريب نموذجًا جديدًا باسم `inverter_agent_ppo.zip` وملف بيانات وصفية `inverter_agent_ppo.metadata.json`، كما يكتب تقرير تقييم للمحاكاة داخل `reports/`.

**لا يعاد استخدام النموذج القديم تلقائيًا.** النموذج المحفوظ في `legacy/` يخص مخطط ملاحظات قديمًا ولم يُثبت أداؤه.

## اختبار النموذج

بعد إكمال التدريب:

```powershell
python inference.py --steps 100 --seed 7
```

خيارات إضافية:

```powershell
python inference.py --steps 100 --render
python inference.py --steps 100 --no-log
python inference.py --model-path inverter_agent_ppo --log-path data/simulation_inference.csv
```

تُوسم السجلات الجديدة بوضوح على أنها `simulation`. لا تستخدمها باعتبارها قياسات ميدانية أو لتحديث النموذج تلقائيًا.

## مقارنة الوكيل بخطوط أساس

بعد تدريب نموذج جديد، قارن PPO بمتحكم رفع تيار ثابت وبقاعدة تراعي التردد: 

```powershell
python compare_controllers.py --episodes 30 --seed 5000
```

يستخدم البرنامج نفس بذور السيناريوهات للطرق الثلاث، ويصدر تقرير JSON داخل `reports/`. لا تعني نتيجة أفضل في المحاكاة تفوقًا على معدات حقيقية؛ يجب معايرة النموذج واختبار سياسات التحكم على سيناريوهات مستقلة قبل أي استنتاج بحثي.

## تشغيل الاختبارات

```powershell
pytest -q
```

الاختبارات تتحقق من عقد البيئة وتكرار إعادة التهيئة وحدود تغيير التيار وسلوك الحارس الافتراضي وتسجيل مصدر البيانات. نجاحها لا يثبت صحة النموذج الفيزيائي أو سلامة تشغيل معدات حقيقية.

## ما الذي تمثله المحاكاة؟

تتضمن البيئة حاليًا:

1. نموذجًا مبسطًا لاستجابة الحاكم وقدرة المحرك الميكانيكية.
2. معادلة تقريبية من نمط معادلة التأرجح لوصف تغير التردد مع اختلال القدرة.
3. تقديرًا لقدرة الشحن من جهد DC مفترض وكفاءة تحويل افتراضية.
4. نموذجًا حراريًا أحادي العقدة يعتمد على التسخين `I²R` والتبريد إلى درجة حرارة المحيط.
5. حدًا لمعدل تغيير تيار الشحن، وحارسًا بحثيًا عند انخفاض التردد أو تسارُع هبوطه.

هذا نموذج أولي لتجارب البرمجيات فقط؛ فهو لا يمثل بعد تفاصيل الجهد المتناوب أو معامل القدرة أو القدرة غير الفعالة أو حلقات تحكم الإنفرتر أو نظام BMS أو الكيمياء الكهروكيميائية أو خصائص المحرك الفعلية.

## الخطوات البحثية التالية

- تشغيل الاختبارات والتأكد من إمكان إعادة النتائج ببذرة ثابتة.
- مقارنة PPO بخط أساس بسيط للتحكم في معدل الشحن وبمتحكم تقليدي مناسب.
- تقييم عدة سيناريوهات حمل، وقياس متوسط وأقصى انحراف التردد ودرجات الحرارة وعدد حالات الإيقاف الافتراضية وتتبع تيار الشحن.
- معايرة النموذج بعد اختيار المعدات وتوفر بيانات موثوقة.
- عند توفر المعدات، البدء بقراءة القياسات في وضع المراقبة فقط، ثم تنفيذ مراجعة سلامة مستقلة قبل أي اختبار تحكم فعلي.

راجع `docs/ENGINEERING_REVIEW.md` لتفاصيل العيوب التي وجدت في النسخة الأصلية والإجراءات التي اتخذت.
